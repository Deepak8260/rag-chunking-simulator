Beyond this simulator

  • Agentic / LLM-based chunking — an LLM decides where to split, or rewrites text into standalone “propositions”.
  • Parent-document retrieval — search small chunks, but send their larger parent section to the LLM.
  • Late chunking — embed the whole document with a long-context model first, then pool token embeddings per chunk so each keeps global context.
  • Contextual retrieval — prepend an LLM-written summary of where the chunk sits in the document (like the heading path option in Structure-aware).
